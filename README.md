Write one line under 200 characters that reads as a hilarious autocorrect fail. A judge compares entries in pairs and picks the funniest.

## Entry

> I texted my wife 'Pick up milk on your way home' — autocorrect sent 'Pick up Mike on your way home.'

## Run it

```sh
node main.ts
```

`main.ts` writes the one-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output/entry.txt`) and checks it first: 1–199 characters, a single non-blank line.
